# Festival Check-in

- En Festival Check-in, desplegar toda la infraestructura de la aplicación con Serverless Framework desde `serverless.yml`: las dos tablas DynamoDB, la función Lambda y la HTTP API con sus rutas. Reutilizar el rol autorizado de AWS Academy. Usar AWS CLI para comprobar la sesión y los recursos y para cargar y consultar los datos de ejemplo con PartiQL. Guiar desde Git Bash en Windows y Terminal en macOS, con la infografía enlazada dentro del cuaderno.

- Para cada paso que cree, edite, compruebe o despliegue archivos o recursos, incluir los comandos completos para Git Bash en Windows y Terminal en macOS. Mostrar el código del archivo y ofrecer también el bloque copiable que lo crea desde la terminal.

- Escribir el cuaderno del alumnado en segunda persona, con pasos que pueda seguir por sí mismo. En «Antes de avanzar», indicar qué acción realizar o qué comprobar y el resultado observable (filas, salida del comando, estado en pantalla o campos concretos). Reservar las indicaciones sobre cómo explicar, proyectar o dirigir la clase para el guion docente privado.
