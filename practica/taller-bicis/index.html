De recepción al taller

Una bicicleta puede volver al taller varias veces. Cada visita tiene su propia orden y se asigna a un mecánico. Al terminar la reparación, registra la hora de cierre.

  1. Consulta la orden

    Con el código de la bici y el número de orden, muestra el trabajo, el mecánico y su estado.

  2. Abre la orden

    Guarda el trabajo, el mecánico asignado y la hora de apertura. Repite la misma petición para comprobar que la orden original se conserva.

  3. Termina la reparación

    Registra la hora de cierre una vez. Una orden terminada conserva la primera hora de cierre.

Antes de avanzar Identifica qué dato permite saber si una orden sigue abierta y qué debe ocurrir al intentar cerrarla dos veces.

Prepara tu proyecto

Comprueba primero tu sesión en Conectar → Comprobación. Desde tu carpeta de prácticas, abre Git Bash en Windows o Terminal en macOS y crea el proyecto. Usa Node.js 22.

node --version
mkdir -p taller-bicis
cd taller-bicis
npm init -y
npm install --save-dev --save-exact serverless@4.45.0
npm install @aws-sdk/client-dynamodb @aws-sdk/lib-dynamodb
mkdir -p src/ordenes
ls -ld src/ordenes

  1. Infraestructura

    Describe en serverless.yml la tabla de órdenes, el índice, las funciones y las rutas. Recupera el rol en Configurar → Rol y elige nombres propios para el stack y la tabla si compartes la cuenta.

  2. Operaciones

    Crea un módulo por acción en src/ordenes. Usa GET, POST y PATCH sobre /bicicletas/{bicicletaId}/ordenes/{ordenId}.

Crea y abre cada archivo desde taller-bicis. En vi, pulsa i para escribir. Guarda con Esc, :wq e Intro.

touch serverless.yml && vi serverless.yml
touch src/ordenes/consultar.mjs && vi src/ordenes/consultar.mjs
touch src/ordenes/abrir.mjs && vi src/ordenes/abrir.mjs
touch src/ordenes/terminar.mjs && vi src/ordenes/terminar.mjs

Desde taller-bicis, comprueba los módulos que hayas creado y despliega con el perfil que verificaste en la misma terminal.

(
  for archivo in src/ordenes/*.mjs; do
    node --check "$archivo" || exit 1
  done
) && npx serverless deploy --stage dev --aws-profile "$perfil"

Antes de avanzar La terminal muestra la URL de tu API y las tres rutas. Guarda la URL para probar la orden.

Prueba y amplía tu taller

En la misma terminal, sustituye PEGA_AQUI_LA_URL por la URL de tu despliegue. Usa una orden nueva si repites el recorrido.

api_url='PEGA_AQUI_LA_URL'
orden="$api_url/bicicletas/bici-014/ordenes/ord-031"
curl -i "$orden"
curl -i -X POST "$orden" \
  -H 'Content-Type: application/json' \
  -d '{"mecanicoId":"mec-03","trabajo":"Ajustar freno trasero"}'
curl -i -X PATCH "$orden"
curl -i "$orden"
curl -i -X POST "$orden" \
  -H 'Content-Type: application/json' \
  -d '{"mecanicoId":"mec-03","trabajo":"Ajustar freno trasero"}'
curl -i -X PATCH "$orden"
curl -i "$orden"
