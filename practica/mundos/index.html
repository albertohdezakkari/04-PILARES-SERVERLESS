      Siguiente · Construir

      Construye desde tu carpeta

      Usa Node.js 22 en Git Bash o Terminal. Comprueba la sesión y recupera tu rol en Festival Check-in → Rol. Ejecuta el primer bloque desde tu carpeta de prácticas.

      Desde la carpeta recién creada, abre cada archivo y escribe tu solución. En vi, pulsa i para escribir. Guarda con Esc, :wq e Intro.

      touch serverless.yml && vi serverless.yml
touch src/registros/consultar.mjs && vi src/registros/consultar.mjs
touch src/registros/crear.mjs && vi src/registros/crear.mjs
touch src/registros/completar.mjs && vi src/registros/completar.mjs

      Declara la tabla, el índice y las tres rutas en serverless.yml. Usa el rol del laboratorio y nombres de servicio y tabla únicos en tu cuenta y región. La API recibe personaId y detalle en el POST. Usa esta misma ruta con GET, POST y PATCH:

      (
  for archivo in src/registros/*.mjs; do
    node --check "$archivo" || exit 1
  done
) && npx serverless deploy --stage dev --aws-profile "$perfil"

      Antes de avanzar Serverless muestra las tres rutas y la URL base. Cópiala para probar.
