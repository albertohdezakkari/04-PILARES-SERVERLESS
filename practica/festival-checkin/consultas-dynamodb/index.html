GetItem La clave completa

Lee un ítem concreto. En una tabla con clave compuesta, envía la de partición y la de ordenación.

En Toolbox GetItemCommandDevuelve Item
01

¿Cómo se llama el evento 1?

EVENT_ID = 1

aws dynamodb get-item --table-name "$tabla_eventos" \
  --key '{"EVENT_ID":{"N":"1"}}'

Busca un único ítem por su clave numérica. En Item verás TITLE con «Festival de otoño».

02

¿Cuál es el perfil de usuario-02?

USER_ID = usuario-02

aws dynamodb get-item --table-name "$tabla_usuarios" \
  --key '{"USER_ID":{"S":"usuario-02"}}'

En Usuarios, la clave es de texto. En Item verás el nombre, los apellidos, el correo y la ciudad del perfil de ejemplo.

03

¿Está usuario-02 inscrito en el evento 1?

EVENT_ID = 1 + USER_ID = usuario-02

aws dynamodb get-item --table-name "$tabla_inscripciones" \
  --key '{"EVENT_ID":{"N":"1"},"USER_ID":{"S":"usuario-02"}}'

La clave de Inscripciones tiene dos partes. Si el pase existe, Item contiene REGISTERED_AT.

04

¿Cómo recupero solo el título?

EVENT_ID = 1

aws dynamodb get-item --table-name "$tabla_eventos" \
  --key '{"EVENT_ID":{"N":"1"}}' \
  --projection-expression TITLE

La clave localiza el evento. --projection-expression elige qué atributo sale en Item.

En el repository · ejemplo 03

const { Item } = await MODELO_INSCRIPCION.build(GetItemCommand)
  .key({ eventId: 1, userId: 'usuario-02' })
  .send();

Query La clave de partición

Lee los ítems del grupo que elijas en una tabla o índice. Puedes acotar el grupo con una condición en la clave de ordenación.

En Toolbox QueryCommandDevuelve Items
05

¿Quién está inscrito en el evento 1?

EVENT_ID = 1

aws dynamodb query --table-name "$tabla_inscripciones" \
  --key-condition-expression 'EVENT_ID = :evento' \
  --expression-attribute-values '{":evento":{"N":"1"}}'

La condición de clave elige el grupo del evento. En Items aparece una lista de inscripciones.

06

¿Qué códigos de ese evento empiezan por usuario-0?

EVENT_ID = 1 · prefijo en USER_ID

aws dynamodb query --table-name "$tabla_inscripciones" \
  --key-condition-expression 'EVENT_ID = :e AND begins_with(USER_ID, :p)' \
  --expression-attribute-values '{":e":{"N":"1"},":p":{"S":"usuario-0"}}'

Primero eliges el evento. begins_with acota la lectura por la clave de ordenación. El ejemplo incluye usuario-02.

07

¿En qué eventos está usuario-02?

PorUsuario · USER_ID = usuario-02

aws dynamodb query --table-name "$tabla_inscripciones" \
  --index-name PorUsuario \
  --key-condition-expression 'USER_ID = :usuario' \
  --expression-attribute-values '{":usuario":{"S":"usuario-02"}}'

El índice agrupa por usuario y devuelve las claves USER_ID y EVENT_ID. Consulta el evento por su ID si quieres el título. Si acabas de inscribir al usuario, la entrada puede tardar en aparecer en el índice.

08

¿Cómo pido la primera página de inscritos?

EVENT_ID = 1 · hasta 1 ítem

aws dynamodb query --table-name "$tabla_inscripciones" \
  --key-condition-expression 'EVENT_ID = :evento' \
  --expression-attribute-values '{":evento":{"N":"1"}}' \
  --limit 1 --no-paginate

--no-paginate deja una sola petición. Si DynamoDB devuelve LastEvaluatedKey, ese objeto es el punto de partida de la página siguiente.

En el repository · ejemplo 05

const { Items } = await MODELO_INSCRIPCION.table.build(QueryCommand)
  .entities(MODELO_INSCRIPCION)
  .query({ partition: 1 })
  .send();

Scan La tabla, sin una clave

Recorre la tabla por páginas. Con un filtro, DynamoDB primero lee y luego aplica la condición.

En Toolbox ScanCommandDevuelve Items
09

¿Qué eventos hay en el catálogo?

Tabla de eventos · sin clave

aws dynamodb scan --table-name "$tabla_eventos" \
  --projection-expression 'EVENT_ID, TITLE'

Recorre la tabla y muestra ID y título. AWS CLI puede pedir varias páginas para completar este comando.

10

¿Qué usuarios son de Huesca?

Filtro CITY = Huesca

aws dynamodb scan --table-name "$tabla_usuarios" \
  --filter-expression 'CITY = :ciudad' \
  --expression-attribute-values '{":ciudad":{"S":"Huesca"}}'

DynamoDB lee la tabla y después aplica el filtro. Compara Count (coincidencias) con ScannedCount (ítems evaluados).

11

¿Cómo guardo la primera página del catálogo?

Tabla de eventos · hasta 1 ítem

aws dynamodb scan --table-name "$tabla_eventos" \
  --limit 1 --no-paginate --output json > pagina-eventos.json
cat pagina-eventos.json

Guarda la respuesta y busca LastEvaluatedKey. Este ejemplo usa una página pequeña. Si solo tienes el evento inicial, puedes crear otro evento para practicar con dos páginas con datos.

12

¿Cómo sigo desde el cursor?

LastEvaluatedKey → ExclusiveStartKey

cursor=$(node -p 'JSON.stringify(require("./pagina-eventos.json").LastEvaluatedKey ?? null)')
if [ "$cursor" != null ]; then
  aws dynamodb scan --table-name "$tabla_eventos" \
    --limit 1 --no-paginate --exclusive-start-key "$cursor"
else
  printf '%s\n' 'No hay otra página.'
fi

Ejecuta antes la consulta 11. Si hay cursor, lo envías completo a DynamoDB para continuar el mismo recorrido. Si se ha agotado la tabla, la respuesta puede venir vacía.

En el repository · ejemplo 11

const { Items, LastEvaluatedKey } = await MODELO_EVENTO.table.build(ScanCommand)
  .entities(MODELO_EVENTO)
  .options({ limit: 1 })
  .send();
