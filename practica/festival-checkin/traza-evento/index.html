Aplica las reglas

El service exige un entero positivo y un título con texto. Si pasan las dos condiciones llama a guardarEvento. Cuando termina la escritura devuelve el ID y el título.

Prueba «Sin título» en el dibujo. ¿Hasta qué capa llega el evento?

src/eventos/crear-evento/service.mjs
import { guardarEvento } from './repository.mjs';

export async function crearEvento(eventId, title) {
  if (!Number.isSafeInteger(eventId) || eventId < 1) {
    throw new Error('Indica un ID de evento entero positivo');
  }
  if (typeof title !== 'string' || title.trim() === '') {
    throw new Error('Escribe un título para el evento');
  }

  await guardarEvento(eventId, title);
  return { eventId, title };
}

Prepara la escritura

El repository prepara PutItemCommand con DynamoDB Toolbox. Solicita a DynamoDB que escriba solo si no existe un ítem con esa clave.

Localiza la condición que protege un evento existente.

src/eventos/crear-evento/repository.mjs
import { PutItemCommand } from 'dynamodb-toolbox/entity/actions/put';
import { MODELO_EVENTO } from '../evento.model.mjs';

export async function guardarEvento(eventId, title) {
  const evento = {
    eventId,
    title
  };

  const comando = MODELO_EVENTO.build(PutItemCommand)
    .item(evento)
    .options({
      condition: { attr: 'eventId', exists: false }
    });

  await comando.send();
}

Traduce los atributos

El repository usa el modelo Evento. savedAs enlaza los nombres de JavaScript con los nombres guardados. La tabla usa EVENT_ID como clave de partición de tipo número.

Busca en el archivo dónde se transforma cada uno de los dos nombres.

src/eventos/evento.model.mjs
import { Entity } from 'dynamodb-toolbox/entity';
import { Table } from 'dynamodb-toolbox/table';
import { item } from 'dynamodb-toolbox/schema/item';
import { string } from 'dynamodb-toolbox/schema/string';
import { number } from 'dynamodb-toolbox/schema/number';
import { db, TABLA_EVENTOS_FCI } from '../datos/dynamo.mjs';

const TABLA_MODELO_EVENTO = new Table({
  name: TABLA_EVENTOS_FCI,
  documentClient: db,
  partitionKey: { name: 'EVENT_ID', type: 'number' }
});

export const MODELO_EVENTO = new Entity({
  name: 'Evento',
  table: TABLA_MODELO_EVENTO,
  entityAttribute: false,
  timestamps: false,
  schema: item({
    eventId: number({ big: true }).key().savedAs('EVENT_ID'),
    title: string().savedAs('TITLE')
  })
});

Comprueba lo guardado

Invoca el handler desde la terminal y luego lee por clave. Compara eventId en la respuesta de Lambda con EVENT_ID en el ítem. En el dibujo, 3 es el ID de ejemplo. Los comandos generan un ID para tu prueba.

Antes de terminar, verifica que el ítem contiene el ID de tu prueba y el título Concierto de aula.

Invoca desde la raíz del clon

printf 'ID del evento de clase: %s\n' "$evento_id"
